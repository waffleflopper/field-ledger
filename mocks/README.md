# Field Ledger Mocks

This folder keeps the mockup source inside the repo so UI docs do not depend on
one developer's `~/Downloads` folder.

## Files

- `HandReceipt Concepts _standalone_.html` is the portable standalone mock.
- `HandReceipt/` contains the source mock components and exported HTML from the
  original mock package.

Use the standalone HTML as the easiest visual reference. Treat the mock as
source of truth for layout, workflow, route responsibility, and product intent,
not as pixel-perfect styling law.
